# 🏆 Rinha de Concurseiro

Sistema de simulados para preparação do concurso da Câmara dos Deputados.

## Estrutura

- `backend/` - API Spring Boot
- `frontend/` - Aplicação React

## Como executar

### Backend
```bash
cd backend
./mvnw spring-boot:run
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
